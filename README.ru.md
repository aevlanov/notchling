# Notchling

**Огонёк в чёлке MacBook, который следит за приложением Claude.**
Пока Claude отвечает, он показывает, что тот делает. Когда Claude просит разрешение, огонёк выскакивает из чёлки, и запрос можно одобрить, не переключаясь в окно.

## Что умеет

- 🔥 **Живой статус.** Пока Claude отвечает, справа от чёлки видно текущий шаг: «Думает…», «Ищет в интернете», «Выполняет команду»…
- ✅ **Разрешения из чёлки.** Когда Claude просит доступ (к папке, файлам, приложению), огонёк выскакивает со звуком и показывает, что именно просят. Кнопки **Разрешить / На эту сессию / Отклонить** нажимают настоящую кнопку в окне Claude. Перед нажатием Notchling проверяет, что на экране всё ещё тот же запрос.
- 💬 **Разрешение в другом чате.** Если разрешения ждёт чат, который сейчас не открыт, огонёк скажет об этом и откроет нужный чат.
- 🎉 **Готово!** Когда ответ дописан, огонёк кувыркается, рассыпает искорки и показывает начало ответа.
- 📄 **Какой файл читается.** Для локальных MCP-серверов показывается точное имя инструмента и путь к файлу (из локальных логов Claude).
- 🎨 **Пять огоньков:** голубой, янтарный, мятный, лунный и сливовый. Глаза следят за курсором; если ткнуть огонька пять раз, у него закружится голова.
- 🔊 **Свои звуки.** Сгенерированы кодом (`tools/make_sounds.py`): колокольчики, пузырьки, шорох огня.
- 🌍 **Русский и английский.** Язык выбирается при первом запуске, потом его можно сменить в меню 🔥 → «Язык».

## Приватность

**Notchling не ходит в сеть. Совсем.**

- В коде нет ни одного сетевого вызова, приложение даже не подключает сетевые библиотеки macOS (Network, CFNetwork). `build.sh` проверяет это при каждой сборке и останавливается, если сетевой вызов появится.
- Нет телеметрии, аналитики, автообновлений и аккаунтов.
- Notchling только **читает** интерфейс окна Claude через Accessibility API и локальные логи `~/Library/Logs/Claude/mcp*.log`. Текст переписки нигде не сохраняется.
- Нажимает он только кнопку разрешения, и только когда вы сами нажали её в чёлке.

Проверить можно самостоятельно: `nm -u ~/Applications/Notchling.app/Contents/MacOS/Notchling | grep -i -E "URLSession|socket|connect"` ничего не выведет. Ещё можно поставить LuLu или Little Snitch.

## Скачать

**[⬇ Скачать последнюю версию](https://github.com/aevlanov/notchling/releases/latest)**: macOS 14+, Apple Silicon и Intel.

1. Распакуй **Notchling-x.y.z.zip** и перетащи **Notchling.app** в **Программы**.
2. Открой. macOS скажет, что не может проверить разработчика: приложение не нотаризовано, для этого нужен платный аккаунт разработчика Apple. Открой **Системные настройки → Конфиденциальность и безопасность**, пролистай вниз и нажми **«Всё равно открыть»**.
3. Включи Notchling в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** и перезапусти его.

Каждый релиз собирается на Маке самого GitHub из этого исходного кода ([workflow](.github/workflows/release.yml)), с той же проверкой на отсутствие сети.

## Сборка из исходников

Нужен macOS 14+ и Command Line Tools (Xcode не нужен):

```bash
xcode-select --install          # если ещё не установлены
git clone https://github.com/aevlanov/notchling.git
cd notchling
bash build.sh
```

`build.sh` соберёт приложение, проверит, что в нём нет сети, подпишет локальным сертификатом «Notchling Local Signing» и установит его в `~/Applications/Notchling.app`. Сертификат создаётся один раз, только в вашей связке ключей; при первом использовании macOS может спросить разрешение для `codesign`.

Потом включите Notchling в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** и перезапустите его. Это нужно, чтобы читать окно Claude.

- **Огонёк**: выбор персонажа.
- **Язык**: русский / English.

## Как это работает

У приложения Claude нет API событий для обычного чата. Поэтому Notchling раз в 0,7 с читает дерево Accessibility окна Claude (Electron открывает его после флага `AXManualAccessibility`) и ищет в нём:

| Что ищем | Что это значит |
|---|---|
| кнопка `Stop response` | Claude отвечает |
| `AXApplicationStatus` = `Running` / `Awaiting input` у чата в боковой панели | чат работает / ждёт разрешения, даже если он не открыт |
| кнопка `<шаг> running` внутри `Currently streaming message` | текущий шаг |
| группа `Permission request…` | карточка разрешения: заголовок, поля, кнопки |
| `Claude responded: …` | начало последнего ответа |

**Ограничения.** Это распознавание интерфейса, а не официальный API. Если Anthropic поменяет подписи в приложении, наблюдатель нужно будет поправить; для этого есть `tools/ax-dump.swift`. Интерфейс Claude сейчас на английском, поэтому шаги переводятся словарём, и незнакомые фразы остаются как есть.

## Разработка

```
Sources/Wisp/WispEngine.swift      огонёк: форма, глаза, анимации, частицы
Sources/App/ClaudeWatcher.swift    наблюдатель за окном Claude, нажатие кнопок
Sources/App/MCPLogTail.swift       чтение логов локальных MCP-серверов
Sources/App/IslandView.swift       вид чёлки (SwiftUI)
Sources/App/IslandWindowController.swift   прозрачная панель над чёлкой
Sources/App/L10n.swift             строки на русском и английском
tools/ax-dump.swift                снимки дерева Accessibility окна Claude
tools/make_sounds.py               генерация звуков (numpy)
tools/preview/wisp.html            превью огоньков в браузере
dev.sh                             пересборка по файлу-сигналу .rebuild
release.sh                         универсальная сборка релиза → dist/Notchling-x.y.z.zip
```

Если создать в папке проекта файл `.devmode`, `build.sh` будет включать подробный журнал в `.diag/`.

Новый релиз: подними `CFBundleShortVersionString` в `Info.plist` и запушь в ветку `release` (`git push origin main:release`) или поставь тег `v0.1.1`. GitHub Actions соберёт zip и выложит его на странице Releases.
